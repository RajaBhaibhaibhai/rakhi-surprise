# Rakhi Surprise

Create a beautiful, mobile-friendly Raksha Bandhan greeting website for my sister.

Theme:

- Elegant purple, pink and gold Raksha Bandhan theme

- Animated floating hearts, flowers and sparkles

- A beautiful Rakhi illustration in the center

- Soft animated background

The first screen should say:

"Happy Raksha Bandhan, 💜"

Show:

"From your bro, Sidhartha Deori"

Add a button:

"Open Your Surprise 🎁"

When she clicks it:

- Play a smooth confetti animation

- Reveal a heartfelt Raksha Bandhan message

- Show an animated Rakhi/gift

- Add a sweet "Karnatak r pora ahute Biryani loi ahi sher r karne👿" message

Make the animations smooth and not too heavy.

Make everything responsive for Android phones.

Put all HTML, CSS and JavaScript in a single HTML file so I can easily publish it.

Do not use external libraries unless absolutely necessary.
